# 다니 이유식 기록장

다니(2026.4.19 출생)의 이유식 1년 플랜(2026.10.19 ~ 2027.10.18)과 가족 기록장입니다.

- `index.html` · 기록장: 끼니별로 먹였는지, 먹은 양, 계획과 다르게 먹인 재료, 분유·우유량, 반응, 메모를 기록해요. 엄마가 승인한 가족만 들어올 수 있어요.
- `plan.html` · 1년 플랜: 단계·원칙, 알레르기 일정, 캘린더형·텍스트형 일정(누구나 볼 수 있는 화면이에요).
- `config.js` · Firebase 연결 설정과 엄마 이메일
- `firestore.rules` · 서버 보안 규칙(승인 목록에 있는 사람만 기록을 읽고 쓰게 막아요)

## 처음 한 번 설정 (약 10분)

### 1. Firebase 프로젝트 만들기
1. https://console.firebase.google.com 에서 구글 계정으로 로그인 → **프로젝트 추가** → 이름(예: `dani-baby-food`) 입력 → Google 애널리틱스는 꺼도 돼요 → 만들기.
2. 왼쪽 메뉴 **빌드 → Authentication → 시작하기 → Sign-in method → Google → 사용 설정** → 프로젝트 지원 이메일 선택 → 저장.
3. 같은 화면 **설정 → 승인된 도메인 → 도메인 추가**에 GitHub 주소의 도메인을 넣어요. 예: `아이디.github.io`
4. **빌드 → Firestore Database → 데이터베이스 만들기** → 위치 `asia-northeast3 (서울)` → **프로덕션 모드**로 시작.

### 2. 보안 규칙 넣기
1. `firestore.rules` 파일을 열어 `OWNER_EMAIL`을 엄마의 구글 이메일(소문자)로 바꿔요.
2. Firebase 콘솔 **Firestore Database → 규칙** 탭에 파일 내용 전체를 붙여 넣고 **게시**.

### 3. 웹 앱 등록하고 config.js 채우기
1. Firebase 콘솔 **프로젝트 설정(톱니바퀴) → 일반 → 내 앱 → 웹(`</>`)** → 앱 닉네임 입력 → 등록.
2. 화면에 나온 `firebaseConfig`의 값 6개를 `config.js`의 `firebase` 칸에 옮겨 적어요.
3. `ownerEmail`에 엄마의 구글 이메일을 넣어요(규칙의 OWNER_EMAIL과 같게).
4. 변경 사항을 GitHub에 올리면 1~2분 뒤 반영돼요.

> `config.js`의 값은 웹 앱이라면 원래 공개되는 값이라 공개 저장소에 올려도 괜찮아요. 기록을 지키는 건 2단계의 보안 규칙이에요.

## 가족 초대하기
1. 엄마가 기록장에 구글 계정으로 로그인 → **가족 승인** 탭.
2. 가족의 구글 이메일을 알면 **이메일로 추가**(기록까지 / 보기만).
3. 또는 가족에게 주소를 보내고, 가족이 로그인해서 **승인 요청**을 보내면 승인해요.
4. 승인을 해제하면 그 즉시 서버에서 막혀요.

## 알아둘 점
- 저장소가 공개라서 `plan.html`과 코드(다니 이름·생일·식단 계획)는 누구나 볼 수 있어요. 기록 데이터는 Firebase에만 저장되고 승인된 사람만 볼 수 있어요.
- 검색엔진에 노출되지 않도록 `noindex`를 넣었지만, 주소를 아는 사람은 플랜 화면을 볼 수 있어요.
- 이 플랜은 참고용이며 의료 조언이 아니에요. 양과 일정은 아기의 반응과 소아과 의견에 맞춰 조절해요.
